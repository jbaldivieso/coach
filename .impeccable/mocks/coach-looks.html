Five looks for Coach

Each look shows the same sample session (Upper A, Thursday 1 October, partway through bench press) on three screens: logging a set, resting, and the session list. The weights and dates are sample data. Swipe sideways through the screens on a phone.

1 Munich ’72

Based on Otl Aicher’s identity for the 1972 Olympics: flat bright color, square tiles, and a drawn pictogram for each lift. Each exercise gets a pictogram and a color, so you can spot it across the room.

Type
Archivo, a grotesque with a width axis. It narrows for big numbers and widens for the wordmark.
Why it fits
Pictograms make exercises recognizable without reading. It’s daylight-bright, with no hint of a dark-mode gym-bro look.
Risk
A white ground can glare in a dim gym. Each new exercise needs a pictogram, or a fallback for ones without.

2 Bumper

Uses the competition plate color code: red 55, blue 45, yellow 35, green 25, white 10. Every set shows the plates you load on each side, so the color tells you what goes on the bar.

Type
Big Shoulders Display, cut like stamped plate lettering, with Barlow Semi Condensed for labels.
Why it fits
Plate math is something you actually do between sets. Rubber black is easy on the eyes in a dim gym.
Risk
It assumes barbell lifts. Dumbbell and bodyweight work have no plates, so they fall back to plain numbers.

3 Attempt Board

Based on the scoreboard at a powerlifting meet. Each set is an attempt card with amber LED numbers and three referee lights that turn white when the set is logged. The rest timer is the platform clock.

Type
Doto, a dot-matrix face, for every number. Sofia Sans Extra Condensed for labels, like on a scoreboard.
Why it fits
Planned, current, and done sets are each obvious at arm’s length. It reads well in a dark gym.
Risk
Dot-matrix numbers are harder to read below about 18px, so small dates need care. It also leans theatrical for a quiet tool.

4 Line Map

A session drawn as a transit map. Each exercise is a colored line and each set is a stop on it. Your current set is the big interchange, and switching exercises is a transfer. An exercise keeps the same color in every session.

Type
Overpass, which is based on Highway Gothic road signage, with tabular figures throughout.
Why it fits
Where you are in the session is always visible. The fixed exercise colors make the history list easy to scan.
Risk
The map idea only works if it stays strict. A loose version turns into dots and lines on a dark blue app.

5 Full Frame

One exercise fills the whole screen in its own color, with the current set in very large numbers. Swipe up to move to the next exercise. During rest, the screen slowly fills with color until it’s time for the next set.

Type
Bricolage Grotesque, condensed down its width axis for numbers you can read from a bench.
Why it fits
It’s the most glanceable option. The phone shows one thing at a time, which matches the gym.
Risk
It’s the biggest structural change. Planning a session and reordering exercises need a separate list mode.

Considered and dropped

  • Graphite console: a dark developer-tool look. It’s close to what Coach looks like now and to every other dark app, so it doesn’t change enough.
  • Star atlas: lovely, but a set has nothing to do with a star chart. The idea would just be decoration.
  • Botanical folio: comparing the same thing across time is a good fit for progression, but cream plates and engraved italics don’t belong in a gym.
  • Type specimen: a weight axis that thickens with the weight lifted is a fun joke, but not a look you could live with.
